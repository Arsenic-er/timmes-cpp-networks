# Source and rights notice

This repository is a private research snapshot of C++ nuclear-reaction-network code.

The reaction-rate and RHS expressions were translated from the supplied Timmes `public_iso7.f90`, `public_aprox13.f90`, `public_aprox19.f90`, and `public_aprox21.f90` source packages. The official distribution and attribution page is:

- F. X. Timmes, [Cococubed: Nuclear Reaction Networks](https://cococubed.com/code_pages/burn.shtml)

The scientific method is described in:

- F. X. Timmes, “Integration of Nuclear Reaction Networks for Stellar Hydrodynamics,” *The Astrophysical Journal Supplement Series* 124(1), 241–263 (1999), [doi:10.1086/313257](https://doi.org/10.1086/313257)

The C++ integration interfaces were developed for [Shiro-Akane/ARCH](https://github.com/Shiro-Akane/ARCH). The validated integrated revision is [ARCH commit `68f401c`](https://github.com/Shiro-Akane/ARCH/commit/68f401cb0edf2bc0bedb3734d9d4cd569d6c56fb).
